SOURCES

Where the data comes from

Every number on this page has a method, a source, and a refresh cadence.

DATA SOURCE · PUBLIC POSTS
Watchlist scan of public posts
Apify Instagram Post Scraper pulls public posts from all watchlist accounts. Returns captions, likes, comment counts, view counts, timestamps, audio metadata, and post URLs. Last 25 posts per creator per run. Only public accounts are scraped.
42 creators · 25 posts each · ~1,050 posts per run · Refreshed bi-weekly
DATA SOURCE · BASELINE METHODOLOGY
Median engagement, not raw views
All engagement figures are shown as a multiplier vs. each creator's personal median across all posts in the bi-weekly dataset. A small creator and a large one can be compared fairly. The post count used to calculate each baseline is shown alongside the multiplier.
Baseline = creator median · All posts in dataset · Bi-weekly window
DATA SOURCE · TEXT DETECTION
On-screen text extraction
Google Vision API Document Text Detection runs on carousel cover slides and reel thumbnails. Detects hook text overlays that don't appear in captions. OCR text is combined with caption and transcript data to identify hook type.
Carousel covers + reel thumbnails · 1,000 free requests/month

How this dashboard is built

01
Collect
GitHub Actions runs every other Sunday at midnight UTC. Apify Post Scraper pulls the last 25 public posts from all 42 watchlist accounts.
02
Classify
Google Vision API runs OCR on carousel covers and reel thumbnails. Spoken audio transcripts are parsed for opening lines and hook text.
03
Score
Each post is scored against the creator's personal median across all posts in the dataset. Posts exceeding 2x baseline are flagged as top performers.
04
Analyse
The enriched JSON is reviewed in a Claude chat session. Full analysis of themes, hooks, open lanes, trend momentum, and 3 custom hooks in Natalie's voice is returned as structured JSON.
05
Publish
analysis.json is committed to GitHub. Vercel detects the commit and redeploys in ~30 seconds. The Notion embed updates automatically.
Raw method
// GitHub Actions scheduler
cron: '0 0 1,15 * *'
// 1st and 15th of each month
 
// Data layer
scrapers: Apify
ocr: Google Vision API
 
// Analysis
analysis: Claude (chat)
 
// Display
hosting: Vercel (free)
embed: Notion iframe
